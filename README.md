
# Expense Tracker Application

## Project Overview
The Expense Tracker Application is a desktop-based application developed using Java Swing. It helps users manage their daily income and expenses, monitor their spending habits, set category-wise budgets, and generate monthly financial reports.

## Features
- **Add Transactions:** Add income and expense records with date, category, amount, and description.
- **Update Transactions:** Modify existing transaction details.
- **Delete Transactions:** Remove unwanted transaction records.
- **Search Transactions:** Search and filter transactions easily.
- **Category Management:** Manage expenses under different categories such as Food, Travel, Shopping, Bills, Health, and Entertainment.
- **Budget Management:** Set spending limits for different categories.
- **Budget Alerts:** Receive alerts when the monthly budget is exceeded.
- **Income and Expense Summary:** Calculate total income, expenses, and available balance.
- **Monthly Reports:** Generate monthly financial reports with category-wise expense details.
- **Export CSV:** Export transaction records into CSV format.
- **Data Persistence:** Store transaction and budget information in text files.

## Technologies Used
- Programming Language: Java
- GUI Framework: Java Swing
- Layout Management: AWT
- Data Storage: Text Files
- File Handling: Java I/O and NIO
- Date Handling: Java Time API
- Development Environment: JDK

# How to Run the Project

1. Install Java JDK on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Compile the Java program:

   javac ExpenseTracker.java

5. Run the application:

   java ExpenseTracker

## Objective
The main objective of this project is to provide a simple and user-friendly application for tracking personal income and expenses, maintaining budgets, and improving financial management.
